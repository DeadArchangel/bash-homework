# Bash — командная оболочка

## Введение

Bash — это командная оболочка, используемая для выполнения команд и создания скриптов. Она широко применяется в Linux и других Unix-подобных операционных системах.

## Условия

В Bash можно использовать `if`, `elif` и `else`. Они позволяют выполнять разные команды в зависимости от заданных условий.

## Циклы

Циклы `for`, `while` и `until` позволяют многократно выполнять команды. Они используются для автоматизации повторяющихся действий.

## Применение Bash

Bash помогает автоматизировать работу с файлами, запускать программы и выполнять системные задачи.

## Заключение

Bash является полезным инструментом для программистов и системных администраторов. Знание условий и циклов позволяет создавать простые и эффективные скрипты.
